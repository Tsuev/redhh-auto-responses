# redhh-ai-responder

Этот репозиторий — модифицированный форк проекта [s3rgeym/hh-ai-responder](https://github.com/s3rgeym/hh-ai-responder).

Инструмент автоматизирует работу соискателя на hh.ru: ищет подходящие вакансии, отправляет отклики, при необходимости генерирует сопроводительные письма, отвечает на сообщения работодателей с помощью AI и поддерживает резюме активным.

> Используйте инструмент только для собственного поиска работы, внимательно настройте фильтры и проверяйте результаты. Файл cookies даёт доступ к аккаунту — не публикуйте и не передавайте его другим людям.

## Быстрый старт

1. Склонируйте репозиторий и соберите приложение:

   ```sh
   git clone <URL_ВАШЕГО_ФОРКА>
   cd redhh-ai-responder
   go build -o redhh-ai-responder .
   ```

2. В браузере войдите в hh.ru и экспортируйте cookies в файл `cookies.txt`. Подойдут расширения [Get cookies.txt LOCALLY для Chrome](https://chromewebstore.google.com/detail/get-cookiestxt-locally/cclelndahbckbenkjhflpdbgdldlbecc) или [для Firefox](https://addons.mozilla.org/en-US/firefox/addon/get-cookies-txt-locally/).

3. Скопируйте пример настроек и укажите AI-провайдер:

   ```sh
   cp example.env .env
   ```

4. В интерфейсе hh.ru настройте поиск вакансий, скопируйте ссылку из адресной строки и добавьте её в `.env`:

   ```env
   REDHH_SEARCH_URL="https://hh.ru/search/vacancy?..."
   REDHH_MAX_APPLICATIONS=50
   ```

   Значение `50` ограничивает один 12-часовой проход 50 попытками, то есть примерно 100 откликами за 24 часа.

5. Запустите программу:

   ```sh
   ./redhh-ai-responder -c ./cookies.txt
   ```

Первый проход запускается сразу. Перед постоянным использованием убедитесь, что в логе выбрано верное резюме и ссылки на вакансии соответствуют вашим фильтрам.

## Что делает программа

- Отправляет отклики на новые подходящие вакансии.
- Генерирует сопроводительные письма для вакансий, где они обязательны, или для всех вакансий с флагом `-force-letter`.
- Решает тесты, если это поддерживает ответ redhh и настроен AI.
- Проверяет чаты с работодателями и автоматически отвечает на новые сообщения.
- Поднимает резюме в поиске и поддерживает статус поиска работы активным.
- Записывает успешные действия и ошибки в JSON-строках в стандартный вывод либо в файл, заданный через `-o`.

Форк умеет разбирать актуальную HTML-экранированную выдачу поиска redhh, в которой данные вакансий содержатся как `&#34;vacancies&#34;`.

## Как работает расписание и лимиты

| Задача | Периодичность |
| --- | --- |
| Поиск и отклики | Сразу после запуска, затем через 12 часов после окончания прошлого прохода |
| Проверка чатов и AI-ответы | Сразу после запуска, затем каждые 15 минут |
| Поднятие резюме | Сразу после запуска, затем каждые 4 часа |
| Активация статуса поиска работы | Сразу после запуска, затем каждые 24 часа |

По умолчанию один проход ограничен 100 попытками отклика. Лимит действует на каждый 12-часовой проход, а не на календарные сутки. redhh также может применить собственный лимит откликов — тогда программа завершит текущий проход и зафиксирует это в логе.

Между HTTP-запросами к hh.ru выдерживается минимум 1,2 секунды. Значение меняется параметром `-request-interval`.

## Настройка AI

По умолчанию используется OpenAI-совместимый API Ollama:

```env
REDHH_AI_BASE_URL="http://localhost:11434"
REDHH_AI_MODEL="llama3:8b"
REDHH_AI_API_KEY=""
```

Для OpenAI или другого совместимого сервиса укажите адрес, модель и ключ, например:

```env
REDHH_AI_BASE_URL="https://api.openai.com"
REDHH_AI_MODEL="gpt-4o-mini"
REDHH_AI_API_KEY="ваш_ключ"
```

При запуске в Docker вместо `localhost` укажите адрес хоста, доступный из контейнера.

## Переменные окружения и параметры

Программа читает `.env` из текущего каталога. Параметры командной строки имеют приоритет над переменными окружения.

| Переменная | Флаг | Назначение |
| --- | --- | --- |
| `REDHH_SEARCH_URL` | `-u` | Ссылка на поиск вакансий с нужными фильтрами. |
| `REDHH_RESUME` | `-r` | Хеш резюме; если не задан, выбирается последнее. |
| `REDHH_MAX_APPLICATIONS` | `-max-applications` | Лимит попыток отклика за один 12-часовой проход; по умолчанию `100`. |
| — | `-mr` | Пропускать вакансии, у которых уже больше N откликов. `0` — не ограничивать. |
| `REDHH_AI_BASE_URL` | `-ai-base-url` | Базовый URL OpenAI-совместимого API. |
| `REDHH_AI_MODEL` | `-ai-model` | Название AI-модели. |
| `REDHH_AI_API_KEY` | `-ai-api-key` | Ключ AI-провайдера. |
| `REDHH_LETTER_PROMPT` | `-letter-prompt` | Дополнительные инструкции для сопроводительных писем. |
| `REDHH_SOLUTION_PROMPT` | `-solution-prompt` | Дополнительные инструкции для решения тестов. |
| `REDHH_CHAT_REPLY_PROMPT` | `-chat-reply-prompt` | Дополнительные инструкции для ответов в чатах. |
| `REDHH_CONTACTS` | `-contacts` | Контакты, которые AI сможет добавить в ответ. |
| — | `-force-letter` | Генерировать сопроводительное письмо для каждой вакансии. |
| — | `-request-interval` | Минимальный интервал между запросами к redhh; по умолчанию `1200ms`. |
| — | `-o` | Файл для JSON-событий вместо стандартного вывода. |
| — | `-l` | Уровень лога: `debug`, `info`, `warn`, `error`. |

Полный список доступен командой:

```sh
./redhh-ai-responder -h
```

### Поиск без `REDHH_SEARCH_URL`

Если ссылка на поиск не задана, программа берёт домен из cookie `redirect_host` или использует `https://hh.ru`. При отсутствии поисковых параметров она добавляет параметр выбранного резюме и ищет подходящие вакансии.

## Запуск

### macOS и Linux

После сборки:

```sh
./redhh-ai-responder -c ./cookies.txt
```

Или используйте скрипт, который сам перейдёт в папку проекта и загрузит `.env`:

```sh
./start.sh
```

### Windows

Соберите бинарник для Windows или поместите `redhh-ai-responder.exe` рядом со скриптом, затем запустите:

```powershell
.\start.ps1
```

### Docker

Подготовьте `.env` и `cookies.txt`, затем выполните:

```sh
docker compose up -d --build
```

## Проверка работы и диагностика

В нормальном логе появляются сообщения вида:

```text
[INFO] Application successfully sent: https://hh.ru/vacancy/...
[INFO] Auto-replied in chat 123456789
```

Полезные сообщения:

- `Application limit reached (100 per run)` — достигнут локальный лимит текущего прохода.
- `Negotiations limit exceeded` — redhh ограничил число откликов; следующий проход будет выполнен по расписанию.
- `Resume not updated` — redhh не позволил поднять резюме в этот момент; остальные задачи продолжаются.
- `invalid byte ... in Cookie.Value` — в `cookies.txt` есть cookie с некорректным значением. Экспортируйте cookies заново, если это мешает авторизации или запросам.

Для подробного журнала запустите:

```sh
./redhh-ai-responder -c ./cookies.txt -l debug
```

## Автозапуск

`start.sh` и `start.ps1` возвращают код завершения приложения. Их можно использовать в systemd, cron `@reboot` или Windows Task Scheduler. Учтите, что после перезапуска программа сразу начинает первый проход.
